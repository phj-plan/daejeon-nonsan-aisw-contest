# 중앙시장 AI 탐험대 — 사용 프롬프트

- 작품명: 중앙시장 AI 탐험대
- 결과물: https://jungang-market-ai-explorer.netlify.app/
- 사용 AI: ChatGPT(기획·초기 제작·배포), Claude(검토·기능 보완·검증)

---

## ① 기획 단계

```
대전 중앙시장 방문객이 입구 근처만 보고 돌아가는 문제를 해결하고 싶어.
방문객의 동행, 머무를 시간, 예산, 목적, 탐험 방식을 입력받아
시장 안쪽까지 둘러보게 만드는 '탐험 미션' 서비스를 기획해줘.
미션을 완료하면 도장을 모으고, 5개를 모으면 참여 점포 혜택으로 연결되는 구조로 만들어줘.
화면 문구는 대전 지역 느낌이 나도록 친근한 충청도 말투("~해봐유")로 써줘.
```

## ② 제작 단계

```
위 기획으로 모바일에서 쓰는 웹 프로토타입을 HTML 파일 하나로 만들어줘.

[화면] 질문 5단계 → 분석 결과 → 오늘의 미션 → 나의 도장판(5칸)
[질문] 누구랑(데이트/친구/가족/혼자), 시간(30분~2시간 이상),
       예산(5천원 이하~상관없음), 목적(먹거리/사진·구경/쇼핑/새로운 곳 발견),
       방식(편하게/알차게/새로운 곳 위주/랜덤)
[미션] 먹거리·사진·쇼핑·발견 4종류, 총 15개
[추천] 선택한 조건과 맞는 미션에 점수를 더 주고, 이미 완료한 미션은 제외
[디자인] 따뜻한 시장 느낌의 베이지·주황 계열, 둥근 카드
```

## ③ 보완 단계

```
지금 코드의 문제를 고쳐줘.
1. 도장판은 5칸인데 미션이 3개만 나와. 미션을 5개로 맞춰줘.
   같은 종류의 미션은 최대 2개까지만 넣어서 다양하게 구성해줘.
2. 사진을 올리지 않아도 도장이 찍혀.
   - 사진·QR 인증은 이미지를 업로드해야만 성공
   - 위치 인증은 GPS로 대전 중앙시장 반경 700m 안일 때만 성공
   - 인증 자료가 없으면 도장을 주지 말고 "도장 받기 실패" 화면을 보여줘
3. 도장을 받았다는 게 잘 안 보여.
   도장이 '쾅' 찍히는 애니메이션을 넣고, 5개를 모두 모으면 축하 효과를 보여줘.
다른 기능은 그대로 두고 수정된 전체 코드를 출력해줘.
```

## [요약본 — 입력칸 글자 수 제한이 있을 때]

```
[기획] 대전 중앙시장 방문객이 시장 안쪽까지 둘러보도록, 동행·시간·예산·목적·탐험 방식을 입력받아 맞춤 탐험 미션을 주고 도장 5개를 모으면 점포 혜택으로 연결되는 서비스를 기획해줘. 문구는 친근한 충청도 말투로.
[제작] 모바일 웹 프로토타입을 HTML 한 파일로 만들어줘. 질문 5단계 → 분석 → 미션 → 도장판 5칸. 조건에 맞는 미션에 가중치를 주고 완료한 미션은 제외해줘.
[보완] 미션을 5개로 맞추고, 사진·QR 업로드나 GPS(시장 반경 700m) 확인이 없으면 "도장 받기 실패"를 띄워 도장을 주지 마. 성공 시 도장 찍히는 애니메이션을 넣어줘.
```
