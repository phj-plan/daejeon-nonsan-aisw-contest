# 🧠 재현 프롬프트 (Reproduction Prompt)

이 문서는 **중앙시장 AI 탐험대**를 생성형 AI(ChatGPT, Claude 등)로 다시 만들 때 쓰는 프롬프트입니다.
아래 코드 블록 전체를 복사해서 AI에 그대로 붙여넣으면 `index.html` 한 파일이 만들어집니다.

## 프롬프트 설계 원칙

| 원칙 | 적용 방법 |
|---|---|
| **역할 지정** | 모바일 웹 프론트엔드 개발자 역할 부여 |
| **출력 형식 고정** | 외부 라이브러리 없는 단일 HTML 파일, 설명 없이 코드만 출력 |
| **데이터 명시** | 질문 5개와 미션 15개를 표로 제공해 결과가 흔들리지 않게 함 |
| **규칙 수치화** | 점수 가중치, 미션 개수, 반경(700m)을 숫자로 지정 |
| **실패 조건 명시** | 인증 자료가 없으면 도장을 주지 않는다는 규칙을 반드시 지키게 함 |
| **검증 체크리스트** | 출력 전에 AI가 스스로 확인할 항목 제공 |

---

## 프롬프트 (복사해서 사용)

````text
# 역할
너는 모바일 우선 웹을 만드는 프론트엔드 개발자야.

# 목표
대전 중앙시장 방문객에게 조건별 맞춤 탐험 미션을 주고,
방문 인증에 성공했을 때만 도장을 찍어주는 웹 프로토타입 「중앙시장 AI 탐험대」를 만들어줘.

# 출력 형식 (반드시 지킬 것)
- index.html 파일 하나 (HTML + CSS + JS 모두 포함)
- 외부 라이브러리, CDN, 빌드 도구 사용 금지 (순수 JavaScript)
- 설명 없이 완성된 코드 전체만 출력
- 화면 문구는 한국어, 친근한 충청도 말투("~해봐유", "~했어유")

# 디자인
- 따뜻한 시장 느낌: 배경 #f4ede2, 카드 #fffaf2, 강조색 #b45b33, 글자색 #302820
- 둥근 카드(radius 24px), 부드러운 그림자
- 모바일 1열 → 700px 이상에서 선택지 4열, 미션 카드 3열
- 상단 오른쪽에 도장 개수 표시 "🏮 0/5"

# 화면 구성 (위에서 아래 순서)
1. 헤더: "🏮 중앙시장 AI 탐험대" + 부제 "AI와 함께 발견하고, 즐기고, 다시 찾는 시장"
2. 히어로: "오늘 시장에서 뭐 해볼까유?"
3. 질문 5단계 (한 번에 한 문항, 진행 바, 이전/다음 버튼, 선택 전에는 다음 비활성)
4. 분석 결과: 선택한 조건 칩 + 추천 이유 한 문장 + [조건 다시 고르기] [새 탐험 만들기]
5. 오늘의 탐험: 미션 카드 5개 + [다른 탐험 생성]
6. 나의 도장판: 5칸, 등급, 최근 기록 5개, 5개 달성 시 [새 도장판 시작하기]
7. 서비스 설명 섹션과 푸터 "대회 제출용 프로토타입"

# 질문 5개
| 키 | 질문 | 선택지 |
|---|---|---|
| party | 오늘 누구랑 왔어유? | 데이트 / 친구 / 가족 / 혼자 |
| time | 얼마나 머무를 예정이야? | 30분 / 1시간 / 2시간 / 2시간 이상 |
| budget | 오늘 예산은 어느 정도야? | 5천원 이하 / 1만원 이하 / 2만원 이하 / 상관없음 |
| goal | 오늘 제일 하고 싶은 건? | 먹거리 / 사진·구경 / 쇼핑 / 새로운 곳 발견 |
| style | 어떤 방식으로 탐험할래유? | 편하게 / 알차게 / 새로운 곳 위주 / 랜덤 |

# 미션 데이터 15개 [id, 카테고리, 제목, 설명, 태그]
m1  먹거리 | 3,000원 이하 간식 찾아보기 | 태그: 5천원 이하, 먹거리
m2  먹거리 | 처음 보는 메뉴 하나 발견하기 | 태그: 새로운 곳 발견, 먹거리
m3  먹거리 | 오늘의 간식 후보 2곳 비교하기 | 태그: 먹거리, 쇼핑
m4  사진   | 시장 안에서 가장 마음에 드는 장면 찾기 | 태그: 사진·구경
m5  사진   | 시장 간판 하나 골라 사진 남기기 | 태그: 사진·구경, 새로운 곳 발견
m6  사진   | 같이 온 사람과 인증샷 남기기 | 태그: 데이트, 친구, 가족, 사진·구경
m7  발견   | 처음 가보는 골목 하나 탐험하기 | 태그: 새로운 곳 발견, 랜덤
m8  발견   | AI가 고른 숨은 재미 찾기 | 태그: 새로운 곳 발견, 랜덤
m9  쇼핑   | 오늘 필요한 물건 한 가지 찾아보기 | 태그: 쇼핑
m10 쇼핑   | 두 점포의 상품 비교하기 | 태그: 쇼핑, 알차게
m11 발견   | 마음에 드는 점포 하나 기억하기 | 태그: 재방문, 편하게
m12 먹거리 | 추천하고 싶은 먹거리 하나 고르기 | 태그: 먹거리, 가족, 친구
m13 발견   | 오늘 처음 알게 된 사실 하나 기록하기 | 태그: 새로운 곳 발견
m14 사진   | 오늘의 탐험 인증 사진 남기기 | 태그: 사진·구경, 재방문
m15 발견   | 다음 방문 때 갈 곳 하나 찜하기 | 태그: 재방문, 편하게
(각 미션에 어울리는 한 줄 설명을 충청도 말투로 붙여줘)

# 미션 생성 규칙
- 한 번에 정확히 5개 생성 (상수 GOAL = 5, 도장판 칸 수와 동일)
- 이미 완료한 미션은 제외
- 점수 = random(0~10)
        + 목적(goal) 태그 일치 25
        + 동행(party) 태그 일치 10
        + 탐험 방식(style) 태그 일치 8
        + ("새로운 곳 발견" 태그 && (style=새로운 곳 위주 || goal=새로운 곳 발견)) 15
        + (budget=5천원 이하 && id=m1) 20
- 점수 높은 순으로 고르되 같은 카테고리는 최대 2개까지, 5개가 안 차면 남은 미션으로 보충
- 남은 미션이 0개면 "모든 미션을 완료했어유" 안내 카드 표시
- 카드에 "미션 1~5" 번호 표시

# 방문 인증 규칙 (가장 중요)
미션 카드의 [📍 방문 인증하고 도장 받기]를 누르면 전체 화면 인증창이 열린다.
인증 방법 3가지:
1. 사진 인증: <input type="file" accept="image/*" capture="environment">로 업로드, 미리보기 표시
2. QR 인증: 매장 QR 사진 업로드 (사진 인증과 같은 방식)
3. 위치 인증: navigator.geolocation으로 현재 위치를 받아
   대전 중앙시장(위도 36.3289, 경도 127.4291)과의 거리를 Haversine 공식으로 계산,
   700m 이내일 때만 성공. 권한 거부·미지원이면 실패 문구 표시

- 인증 방법을 고르면 [인증 확인하기] 버튼 활성화
- 확인을 눌렀을 때:
  - 사진/QR인데 업로드한 이미지가 없으면 → 실패
  - 위치인데 반경 안이 아니면 → 실패
  - 실패하면 도장 개수를 절대 늘리지 않는다
- 이미 완료한 미션은 중복 지급하지 않는다
- 도장이 이미 5개면 인증 대신 "이미 5개를 모두 모았어유" 안내

# 결과 애니메이션
- 성공: 빨간 원형 도장(🏮 / 인증 완료 / 중앙시장 탐험대)이
  scale(3)→scale(1)로 회전하며 찍히는 애니메이션 + 잉크가 퍼지는 원 효과
  + 상단 카운터가 튀는 효과 + 도장판의 새 칸이 튀어나오는 효과
  + 제목 "도장 획득! (n/5)", 버튼 "계속 탐험하기"
- 실패: 인증 카드 좌우 흔들림 + 회색 ✖ 도장 "인증 실패"
  + 제목 "도장 받기 실패" + 실패 이유 + 버튼 "다시 인증하기"
  (닫으면 인증창이 그대로 남아 바로 재업로드 가능)
- 5개 달성: 🏆 "탐험 완주" 도장 + "도장 5개 완성! 중앙시장 마스터" + 색종이 효과
- 성공한 미션 카드는 초록 배경으로 바뀌고, 업로드한 사진 썸네일과 "✅ 방문 인증 완료 · 도장 획득" 표시

# 도장판
- 등급: 0~2개 🌱 시장 새싹 / 3~4개 🥟 시장 탐험가 / 5개 🏆 중앙시장 마스터
- 최근 기록 5개를 "🏮 미션명 (사진 인증)" 형식으로 최신순 표시
- 상태 {stamps, done[], history[]}를 localStorage "marketQuest"에 저장
- localStorage 읽기/쓰기는 모두 try/catch로 감싸서 저장이 막힌 환경에서도 동작

# 코드 규칙
- 요소 접근은 const $ = id => document.getElementById(id) 사용
  (id를 전역 변수처럼 쓰지 말 것. 특히 history 같은 이름은 window.history와 충돌함)
- 모달은 alert/confirm 대신 직접 만든 오버레이 사용
- 주요 블록에 한국어 주석

# 출력 전 스스로 확인할 것
- [ ] 미션이 항상 5개 나오는가 (남은 미션이 5개 이상일 때)
- [ ] 사진 업로드 없이 확인을 누르면 "도장 받기 실패"가 뜨고 도장 수가 그대로인가
- [ ] 업로드 후 확인하면 도장 애니메이션과 함께 도장 수가 1 늘어나는가
- [ ] 같은 미션을 두 번 인증할 수 없는가
- [ ] 도장 5개에서 완주 화면과 "새 도장판 시작하기" 버튼이 나오는가
- [ ] 콘솔 에러가 없는가
````

## 수정 요청 예시 (후속 프롬프트)

```text
위 index.html에서 다른 부분은 건드리지 말고,
위치 인증 허용 반경을 700m에서 300m로 바꾼 전체 코드를 다시 출력해줘.
```

> 후속 요청에는 **"다른 부분은 건드리지 말고"**와 **"전체 코드 출력"**을 넣어야 AI가 기존 기능을 빠뜨리지 않습니다.
